# ⚙️ backend/: API server ও AI agent

এখানে থাকবে:
- Agent ১: প্রেসক্রিপশন পাঠক (ছবি → structured JSON)
- Agent ২: যাচাইকারী (ওষুধের database মেলানো + confidence)
- Agent ৩: Schedule পরিকল্পনাকারী
- Agent ৪: বাংলা সহকারী
- Agent ৫: শেখা ও পর্যবেক্ষণ
- SMS / call escalation (version 2)

> API key কখনো কোডে লিখবেন না। `.env` ফাইলে রাখুন (রুটের `.env.example` দেখুন)।
