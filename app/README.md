# 📱 app/: Flutter মোবাইল অ্যাপ

এখানে থাকবে:
- Onboarding (ফোন নম্বর, permission, battery গাইড)
- প্রেসক্রিপশন স্ক্যান ও confirm স্ক্রিন
- Offline alarm engine (AlarmManager, BOOT_COMPLETED)

- Caregiver স্ক্রিন
